# Entrenamiento Local — BETA (IndexedDB)

Versión de pruebas de `Entrenamiento-local` con almacenamiento ampliado (localForage / IndexedDB).
Usa una base de datos separada (`entrenamiento_total_beta`): copia los datos de `localStorage` sin borrarlos ni modificarlos.
La app de producción no se ve afectada. Antes de probar, pulsa «Exportar JSON» en la app de producción.
